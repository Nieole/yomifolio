# 16: 识别图片原语

**What to build:** 有视觉能力的 agent 可以按需查看一个系列的本地封面、指定页的缩略图和证据包里候选的封面，用来区分相似的候选。弱模型不调用这个原语，也能走完主循环。

**Blocked by:** 05 证据包预取（手动回填）

**Status:** ready-for-agent

- [ ] 一个按系列调用的原语（`read`），返回三类图片：本地封面、指定的 1 到 3 页缩略图、证据包候选封面的缩小图。
- [ ] 候选封面由服务端只从已知来源的域名拉取。以下情况一律拒绝：其它域名、重定向到其它域名、文件过大、内容不是图片。不接受调用方提供的 URL。
- [ ] 沿用现有的图片体积预算和 MCP 传输上限；超出时如实报告，不截断成损坏的图片。
- [ ] 本地图片沿用现有的内容访问资格检查和句柄释放。
- [ ] 新工具的描述在约 400 字符以内并附调用示例，结果带 JSON 文本副本。
- [ ] 集成测试由来源替身提供封面，覆盖域名限制、体积预算和拉取失败。
- [ ] 后端门禁通过。

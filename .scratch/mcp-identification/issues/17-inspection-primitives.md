# 17: 巡检原语

**What to build:** 只读的 agent 能在全库巡检疑似重复、目录分组和标签方面的问题，并把发现上报给所有者，但不能改动任何内容。

**Blocked by:** 06 主循环：领取与提交裁决

**Status:** ready-for-agent

- [ ] 查重（`read`）：在凭据授权的所有资料库中，按规范化名称和识别结论（指向同一来源条目）查找疑似重复的系列，支持分页。
- [ ] 标签统计（`read`）：在授权范围内统计标签的使用情况，支持分页。
- [ ] 独立上报工具（`read`）：提交非识别类上报，即疑似目录分组错误、疑似重复、标签问题。上报作为备注保存，不改变识别状态；复用 06 的上报存储。
- [ ] 只有 `read` 能力的凭据和普通用户的凭据都能使用这三个工具，但都不能领取系列或写入。
- [ ] 新工具的描述在约 400 字符以内并附调用示例，结果带 JSON 文本副本。
- [ ] 集成测试覆盖查重、统计、上报和权限边界。
- [ ] 后端门禁通过。

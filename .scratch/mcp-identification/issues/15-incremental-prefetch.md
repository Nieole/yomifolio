# 15: 增量预取

**What to build:** 增量整理不再需要所有者手动操作：
- 扫描出新系列后，自动为它们准备好证据包；
- 证据包太旧时，在被领取时刷新；
- 新启用一个来源后，查无此作的系列对这个来源重新开放。

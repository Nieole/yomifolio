# 18: 作品群关系写入

**What to build:** agent 可以给一个系列添加续作、外传等作品群关系，每次添加都留下收据，并且可以撤销。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 原语（`metadata_write`）在两个系列之间添加关系：关系类型沿用现有的作品群关系类型，两个系列都必须在凭据的授权范围内。
- [ ] 每次添加都要写原因、留收据，可以查询和撤销。撤销只移除本次添加、之后没被改动过的关系。
- [ ] 作品群的推导重建沿用现有机制（ADR 0012），不另造一套。
- [ ] 不提供删除既有人工关系的能力。
- [ ] 新工具的描述在约 400 字符以内并附调用示例，结果带 JSON 文本副本。
- [ ] 集成测试覆盖添加、撤销、跨授权范围被拒绝。
- [ ] 后端门禁通过。

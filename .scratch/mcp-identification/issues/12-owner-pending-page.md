# 12: 待人工页

**What to build:** 所有者在一个页面处理所有需要人看的系列：识别类上报、待复核的系列和非识别类备注。在这里挑中候选，就完成了该系列的整理。

**Blocked by:** 06 主循环：领取与提交裁决；07 识别后的元数据补充；09 重搜单个系列

**Status:** ready-for-agent

- [ ] 列出识别类上报、待复核的系列和非识别类备注，显示证据包和 agent 给的理由；可以按分类筛选，支持分页。
- [ ] 挑候选：记为人工确认的识别，并立即按 07 补充元数据。
- [ ] 否决候选：记为排除候选，该候选从证据包中消失。
- [ ] 判为查无此作：记录搜过的来源。
- [ ] 自定义重搜：复用 09。
- [ ] 设为已审定：复用 03。
- [ ] 关闭非识别类备注；关闭不改变识别状态。
- [ ] 所有人工操作都走管理员网页接口，受管理员权限约束；新的响应结构纳入生成契约，无漂移。
- [ ] 测试：前端组件测试覆盖上述操作和冲突时的呈现；后端集成测试覆盖每个操作导致的状态变化。
- [ ] 后端门禁、前端 test/build/lint 通过；提交时附 UI 截图。

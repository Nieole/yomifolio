# 10: 作者校正与封面改善成为独立原语

**What to build:** 把 agent 需要自己判断的两类改动从逐系列补充命令中拆出来，成为独立操作，规则不变：一类是系列内作者校正，另一类是用本系列的归档页改善自动封面。这一步为 19 下线旧补充命令做准备。

**Blocked by:** 02 元数据补充与证据来源解耦；06 主循环：领取与提交裁决

**Status:** ready-for-agent

- [ ] 作者校正：
  - 只调整目标系列的作者关联，不改共享作者记录；
  - 被替换的作者必须属于当前作者，替换后的作者必须有该系列已识别来源的证据支持；
  - 按整组校验期望值，写原因、留收据，可以撤销。
- [ ] 封面改善：
  - 只接受授权范围内同一系列的归档书和页码，并附一段比较说明；
  - 只改未锁定的归档自动封面，人工封面受保护；
  - 文字和封面在同一操作中一起生效的保证不变。
- [ ] 两个原语（`metadata_write`）的结果和收据都与现有补充一致，可以用现有工具查询、撤销、清理。
- [ ] 新工具的描述在约 400 字符以内并附调用示例，结果带 JSON 文本副本。
- [ ] 现有作者校正和封面相关的集成测试迁移到新原语上，用等价断言后仍然通过。
- [ ] 后端门禁通过。

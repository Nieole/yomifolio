# 08: 标签策略

**What to build:** 识别补充开始追加标签，但只追加通过过滤的内容标签，「漫画」「日本」「已购」这类噪声不会进入藏书。

**Blocked by:** 07 识别后的元数据补充

**Status:** ready-for-agent

- [ ] Bangumi 结果保留标签的投票数，证据包和识别结论保存带投票数的标签。
- [ ] 标签依次经过三道过滤：
  - 来源投票数阈值；
  - 可配置的黑名单，覆盖媒介、地区、年份、个人状态等；
  - 每个系列的追加上限。

  三项的默认值在本票确定，并写入配置模板。
- [ ] 只追加，不删除已有标签。多个已识别来源的标签先取并集，再过滤。
- [ ] 对没有投票数的来源，以及本票之前生成、缺少投票数的证据包，处理规则要写明并有测试。
- [ ] 配置变更即时生效，沿用统一的配置管理。
- [ ] 集成测试覆盖：阈值、黑名单、上限、多来源并集。
- [ ] 后端门禁通过。

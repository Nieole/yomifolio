# 05: 证据包预取（手动回填）

**What to build:** 所有者手动启动预取后，服务端在后台为未处理的系列做多来源搜索，把本地线索和候选整理成证据包持久保存。网页上原有的全库、资料库两个批量刮削入口，改为启动预取。

**Blocked by:** 01 多来源搜索扇出成为可复用能力；03 识别结论与识别状态

**Status:** ready-for-agent

- [ ] 预取作为一次普通运行出现在任务中心，有进度，可以暂停和取消。中断后再次发起时，从还没有可用证据包的系列继续。
- [ ] 只处理未处理的系列。已识别、已审定、待人工的系列不预取。
- [ ] 搜索词由服务端确定性地生成多个变体：先清洗目录名中的卷号、汉化组、方括号标签等噪声，再加入 ComicInfo 的系列名与作者。
- [ ] 证据包只含文本，内容如下：
  - 本地线索：目录名、书数、前几本书的文件名，以及 ComicInfo 中的系列名、作者、年份；
  - 候选：每个来源最多 3 条，含标题、原名、作者、年份、卷数、简介摘要；
  - 比对信号：附在每条候选上，例如标题规范化后是否一致、作者是否与 ComicInfo 一致、来源卷数与本地书数。比对信号不以概率形式呈现。
- [ ] 排除候选不进入证据包；证据包记录抓取时间。
- [ ] 各来源的限速由服务端统一控制，测试配置可以关闭限速。单个来源失败时记为不可用，其它来源的候选照常保存。
- [ ] 两个批量刮削入口改为启动预取，不再生成取第一条结果的提案。单系列刮削入口不变。
- [ ] 进度查询增加预取情况：已就绪和待预取的系列数。
- [ ] 集成测试通过 `bootstrap.Options.Sources` 注入能记录调用的来源替身，断言：搜索词变体、关闭限速后的扇出、来源失败隔离、排除候选被剔除。
- [ ] 后端门禁、前端 test/build/lint 通过，生成契约无漂移。

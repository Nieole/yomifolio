# 02: 元数据补充与证据来源解耦

**What to build:** 元数据补充的核心部分可以接受提案以外的证据来源，为「识别确认后由服务端补充」铺路。核心部分包括：按字段校验期望值、写入字段、追加集合成员、留收据、写字段来源记录、撤销。这是纯预备重构，外部行为不变。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 补充拆成两段：「从已确认提案收集字段证据」和「把字段证据应用到系列并留收据」。后一段不再假设证据来自提案。
- [ ] 字段来源记录、以及撤销时回收这些记录，都可以关联到提案以外的证据来源（例如一条识别结论）。撤销只回收本次操作写入的来源记录。
- [ ] 以下功能的外部行为与收据格式不变：现有的补充、批量补充、提案裁决、撤销与清理。现有集成测试不改断言即通过。
- [ ] ADR 0011 的事务内终态守卫保持不变。
- [ ] 后端门禁通过。

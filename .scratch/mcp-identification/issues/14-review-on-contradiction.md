# 14: 待复核检测

**What to build:** 已识别的系列加入新书时，如果新书的本地线索与识别结论矛盾，系列转为待复核，等人确认；不矛盾就什么都不做。

**Blocked by:** 03 识别结论与识别状态

**Status:** ready-for-agent

- [ ] 扫描新增书之后，检查 ComicInfo 系列名等本地线索是否与该系列的识别结论矛盾，比对时把原名和别名也算进去。矛盾的判据在本票确定，并写入规格。
- [ ] 判定为矛盾时，系列转为待复核，原识别带来的字段不变；不矛盾或者没有线索时，状态不变。
- [ ] 检查过程不访问外部来源，不阻塞扫描主流程；检查出错不会导致扫描失败。
- [ ] 待复核的系列出现在进度计数和系列详情页里。
- [ ] 集成测试用真实扫描，分别加入 ComicInfo 矛盾和不矛盾的书。
- [ ] 后端门禁通过。

## Comments

**用户决定（2026-11-25）**：扫描侧保护带来源记录的值，本票实现。现状是已有系列加入带 ComicInfo 的新书或强制重扫时，`PrepareScanUpdate` 用 ComicInfo 覆盖或清空未锁的标量，连载状态没锁就总被清空。改为：字段当前值有来源记录、且与记录值一致（识别补充或历史提案应用写入的）时，扫描不覆盖也不清空；没有来源记录的字段照旧由 ComicInfo 覆盖。不为此加锁，保证 agent 的「改正字段」仍然可用。

# 09: 重搜单个系列

**What to build:** 遇到难判的系列，agent 或所有者可以用自定义搜索词再搜一次，结果并入该系列的证据包。

**Blocked by:** 05 证据包预取（手动回填）

**Status:** ready-for-agent

- [ ] MCP 原语（`metadata_write`）和管理员网页接口共用同一个用例。
- [ ] 复用 01 的扇出和来源限速。
- [ ] 结果按证据包规则并入：每个来源的候选数有上限、附比对信号、剔除排除候选；原有候选不丢弃；记录本次的搜索词和时间。
- [ ] 搜索词的长度和内容有限制。
- [ ] 耗时的搜索作为一次运行，可以查询和取消；断线不会取消它。
- [ ] 新工具的描述在约 400 字符以内并附调用示例，结果带 JSON 文本副本。
- [ ] 集成测试覆盖：并入、去重、剔除排除候选、来源失败。
- [ ] 后端门禁通过，生成契约无漂移。

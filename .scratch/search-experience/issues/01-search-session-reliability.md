# 01: 搜索等待、失败与旧响应隔离

**What to build:** 读者通过现有全局搜索就能区分正在等待、请求失败与成功无结果，并能重试；快速输入、切换范围、关闭或重置后，不再误选旧查询结果。本票沿用现有首批查询，不提前实现继续加载。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 按本 effort 正式规格的搜索会话行为，区分空输入提示、防抖等待、请求中、成功有结果、成功无结果及失败。只有当前请求成功且为空才显示“未找到”；首批失败可以对当前查询立即重试。
- [ ] 保留约 300ms 输入防抖；重试不重复等待防抖。新关键词或 target 立即清除旧结果与可选择资格，不仅在请求完成后才替换。
- [ ] 请求取消与请求代际、查询归属校验共同生效；即使旧请求取消无效且晚到，也不能覆盖新查询或回填已关闭的搜索。
- [ ] 关闭、重置、有效读者或连接上下文变化时使旧请求与结果失效；重新打开对保留输入重新查询，不复用未验证结果。不新增假想 transport adapter。
- [ ] 键盘上下选择、回车与鼠标只作用于当前有效条目；无有效条目时不导航、不越界。系列进入详情、书进入阅读的行为保持不变。
- [ ] 等待和错误文案遵循既有本地化，异步状态可被辅助技术感知；不改变权限、检索字段或既有首批排序。
- [ ] 通过已有搜索会话与弹窗高层 seam，控制真实 HTTP adapter 的响应完成顺序，覆盖取消无效、快速输入、切范围、关闭/重开、重置、失败重试及键盘安全；不能只给弹窗注入静态 hits。
- [ ] 本票前端测试、构建及 lint 通过；如修改 HTTP 行为，补实际入口回归。记录执行证据与未执行限制。本票不依赖归一化或新分页契约，不能等待后续票才验证自身行为。

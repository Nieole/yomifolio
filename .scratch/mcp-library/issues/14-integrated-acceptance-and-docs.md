**What to build:** 部署者可按文档配置 HTTP 或 stdio 接入，管理员可管理委托权限，通用客户端完成发现、匹配、受保护整理、运行控制和恢复链路；以综合测试证明各纵向切片组合后仍遵守已确认边界。

**Blocked by:** 03 通过 stdio 辅助进程连接同一服务；11 裁决已有提案并关闭剩余差异；12 按本次额度调用内部 LLM；13 独立授权清理撤销材料。

**Status:** ready-for-agent

- [ ] 双传输均验证初始化、工具发现和实际调用；stdio 真实子进程连接生产组装服务，复用同一业务验收宿主，不另造应用运行时。
- [ ] 完整链路包含受限凭据、组合筛选、本地和图片线索、多来源匹配、歧义不写入、补充与作者校正、文字封面一致性、提案关闭和逐系列结果报告。

# 01: 打通生产组装的外部来源测试替身

**What to build:** 后续功能可通过生产组装的完整服务接受确定性来源数据，不访问真实站点或产生模型费用；保持正常启动、恢复、关闭及现有业务行为不变。这是唯一前置预重构，不另造一套业务测试宿主。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 沿现有 bootstrap 集成测试方式使用真实临时 SQLite、资料库、归档和图片，只在外部元数据与 LLM 来源边界注入替身，不替换应用用例、数据库或任务引擎。
- [ ] 测试可控制来源返回值、错误及阻塞时机，供以后从公开接口验证取消、竞争与费用边界，不依赖盲等或内部调用顺序。
- [ ] 通过生产服务公开 HTTP 验证替身确实由同一应用运行时使用；无注入时仍使用现有生产来源，启动与恢复失败不暴露半组装服务。
- [ ] 不增加新的产品工具、权限或工作流，不机械重构无关调用方，不静默修改现有来源行为。
- [ ] 生产组装、共享任务队列、资源释放和 shutdown/drain 回归通过；后端测试、格式与 lint 通过。

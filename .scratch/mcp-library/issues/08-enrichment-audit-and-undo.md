# 08: 安全补充元数据并支持追溯和撤销

**What to build:** agent 可对已确认匹配的系列补充描述、标签、链接和缺失评分；每次系列变更可以通过网页或 MCP 查明来源、前后状态及结果，并安全撤销。此票不包含作者校正或封面切换。

**Blocked by:** 07 检索多来源候选并形成有依据的提案。

**Status:** ready-for-agent

- [ ] 描述只补空，保留非空值及锁定字段；筛选内容标签后追加、不删除已有成员、不纳入个人标记与来源噪声，补充来源链接。
- [ ] 缺失评分使用有效站点评分统一为十分制后等权平均，一个来源即采用其值；保存原分数、尺度与公式，不覆盖现有评分，不引入个人评分或模型自评。
- [ ] 所选字段在单系列操作中一起成功或不生效；涉及字段当前值变化及锁定检查在提交边界生效，无关字段变化不阻止，标签按整组检查。
- [ ] 写入前重新校验当前用户和凭据权限；不同系列允许部分成功，结果区分实际变更、无变化、冲突、失败及未处理，不误称整批原子操作。
- [ ] 持久记录操作身份、目标系列、前后状态、字段来源与短理由，不把当前字段最新沿革当成完整操作审计；定义重试与操作查询语义，避免重放谎报新变更。
- [ ] 网页管理员和授权 MCP 可查询记录与撤销；撤销只在涉及字段仍符合预期且当前锁和权限允许时生效，后续标签整组变化拒绝覆盖，无关字段编辑不阻塞。
- [ ] 默认保留撤销材料，不引入自动到期；撤销后网页及 MCP 查询反映实际恢复结果，重开服务仍可追溯并执行符合条件的撤销。
- [ ] 主验收经生产服务公开接口、真实存储及网页查询覆盖补充、评分、并发冲突、撤销和多系列部分成功；补管理员页面交互测试。
- [ ] 保留人工编辑、扫描集合及普通提案原有语义；后端和前端门禁、SQL 与响应契约生成物检查通过，更新所属长期契约。

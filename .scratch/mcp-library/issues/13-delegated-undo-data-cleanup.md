# 13: 独立授权清理撤销材料

**What to build:** 管理员可在网页显式清理旧操作的撤销材料，也可独立授权 agent 自主清理；清理后仍能追溯最小审计，但系统明确不再保证恢复对应内容，不损坏在用图片或藏书。

**Blocked by:** 10 改善自动封面并与文字一起生效。

**Status:** ready-for-agent

- [x] 默认不按时间自动清理撤销材料和必要旧图片；管理员网页提供手动清理入口，MCP 提供独立能力控制的同等操作。
- [x] 元数据写入权限不隐含清理权限；服务端执行当前用户、凭据资料库及清理能力交集，猜测操作标识不能清理其他作用域材料。
- [x] 按 mm-adr-0016 草案记录的边界，获授权 agent 可自主清理且不要求逐批人工确认，不能自行授予或扩大清理权限。
- [x] 清理前后记录和结果明确说明哪些变更不再保证可撤销；保留最小审计摘要，不让材料缺失表现为仍然完整可恢复。
- [x] 绝不删除仍在使用的图片或藏书文件，处理同一图片被多个记录或当前封面引用的情况；清理与撤销、换封面竞争不能造成误删或虚假恢复成功。
- [x] 操作的失败、部分清理及重复请求如实报告；耗时清理遵守既有委托运行与撤权检查，不引入第二套清理任务生命周期。
- [x] 真实服务、文件及公开图片查询验证权限拒绝、自主清理、默认保留、共享图片保护和清理后审计；补管理页损失提示和结果测试。
- [x] 后端及前端门禁和受影响生成检查通过；长期契约明确清理与删除藏书文件的区别。

# 10: 改善自动封面并与文字一起生效

**What to build:** agent 可在比较质量后替换系列的自动封面；如果本次同时补充文字，两者在该系列内全部成功或不生效，保留旧图片以便安全撤销，人工封面始终受保护。

**Blocked by:** 05 读取受限封面和书页缩略图；08 安全补充元数据并支持追溯和撤销。

**Status:** ready-for-agent

- [ ] 仅允许改善归档自动生成的封面；手选、上传及受当前锁保护的封面不可替换，提交边界再次检查授权、封面归属和预期当前状态。
- [ ] 图片先准备，随后与本次文字一起生效；图片获取或准备失败、字段冲突、锁变化和权限失效均不导致系列半提交。
- [ ] 选定并记录数据库与图片切换的故障一致性方案，包含资源清理及服务重开行为；不以单个数据库事务代称跨存储原子性，不回滚外部请求或费用。
- [ ] 保留必要旧图片与操作前后状态，网页与 MCP 记录可核查；在当前内容和锁仍允许时，撤销一起恢复涉及文字及旧封面。
- [ ] 对后续人工换封面或相关文字变化安全报冲突，不覆盖新内容；不同系列依然允许部分成功。
- [ ] 通过实际公开封面读取和系列查询验证成功、准备失败、提交冲突、撤销及故障后重开，不仅检查内部引用或存在的图片文件。
- [ ] 保留人工封面和内容句柄回归；完善管理页差异呈现，后端及受影响前端门禁和生成物检查通过。

# 09: 校正所选系列的作者关联

**What to build:** agent 可为目标系列追加作者、归并别名和修正角色，同时保留其他系列的作者信息；这些校正具备与其他补充操作一致的追溯、冲突保护和撤销能力。

**Blocked by:** 08 安全补充元数据并支持追溯和撤销。

**Status:** ready-for-agent

- [x] 提供目标系列内的作者追加、别名归并及角色校正，明确这是保留既有成员规则的获准例外，不扩展为全库作者归并或其他字段覆盖。
- [x] 通过调整该系列关联完成校正，不修改共享作者身份行的名称或角色影响其他系列；覆盖多个系列共用同一作者身份的场景。
- [x] 提交与撤销都执行当前授权、字段锁及作者整组预期值校验；后续任何作者组变化报冲突，无关字段修改不阻止。
- [x] 复用单系列操作与前后状态记录，保留校正来源及理由；可与已有补充字段一起提交，失败不留下部分校正。
- [x] 网页和 MCP 可查询校正差异并安全撤销；恢复目标系列关联但不破坏其他系列及已有作者数据。
- [x] 经生产服务与真实存储验证共享身份隔离、角色变化、集合冲突、事务失败和重开后撤销；补必要 UI 回归，后端及受影响前端门禁和生成物检查通过。

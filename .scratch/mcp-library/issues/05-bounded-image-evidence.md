# 05: 读取受限封面和书页缩略图

**What to build:** agent 可以读取目标系列的封面和自行选定的少量书页缩略图以辅助识别，不能借此下载整本书或读取任意文件。

**Blocked by:** 04 筛选待整理系列并读取本地识别线索。

**Status:** ready-for-agent

- [ ] 通用 MCP 客户端能读取授权范围内封面和指定页缩略图；工具契约明确每次页数、图片尺寸及整体响应体积硬上限。
- [ ] 越界页码、过多页、过大响应、无效对象与非授权资料库请求得到明确结果，不回退为原始归档或任意文件下载。
- [ ] 复用既有内容访问资格与句柄释放，成功、失败、取消及客户端断连均不遗留归档借用或文件资格。
- [ ] 上限是工具响应预算，不照搬归档解析器大条目安全上限；对于大书仍只获取有限证据。
- [ ] 在真实临时图片和归档上通过公开客户端验证内容、限制和授权，保留内容句柄及路径迁移相关回归。
- [ ] HTTP 入口可验收完整行为，stdio 沿同一工具契约转发；后端门禁通过。

# 功能、客户端与可选工具

[中文首页](../README.zh-CN.md) · [English guide](features.md) · [部署与安全](getting-started.zh-CN.md)

## 藏书、搜索与可选能力

- **扫描与格式：** ZIP/CBZ、RAR/CBR 及内嵌 ComicInfo 导入；仅 ZIP/CBZ 支持 ComicInfo 原子写回，不支持 EPUB/PDF。封面默认 WebP、400px 宽，也可用 AVIF，失败可回退 JPEG。SQLite 驱动本身无需 CGO，不代表整体程序无需 CGO。
- **扫描档位与维护：** `fast_scan`、`metadata_scan`（默认，不计算完整内容哈希）、`identity_scan`、`repair_scan`。重复文件内容检测需先生成哈希；可仅移除索引或将原文件移至数据库旁的 `trash`（默认 `data/trash`），不直接永久删除源文件。归档页图解压有单条目 256 MiB 上限；可按库开启 `watch` 递归监听；库根不可达或超过 50% 系列疑似丢失时中止清理。IO 策略可调整扫描/解压/封面/哈希并发、阅读时降载、空闲重任务与同盘缓存。路径迁移保留支持场景下的身份，但不替用户搬文件，也不推断任意库内重排。
- **搜索与组织：** 按系列/卷册名称与标题跨库搜索，FTS5 trigram、短词 gram 与子串回退，附封面/相关度。作者/标签是结构化筛选，不是全文检索对象。手动合集、有序阅读列表、AND 组合的单值智能筛选及静态快照；系列/全库关系图与自动 Franchise 合集（大库图谱有服务端约 4000 关系、前端约 200 节点限制）。支持标签改名/合并/删除、自定义键值字段整表替换、批量标签/状态/出版社/收藏/读态编辑；作者目前仅列表与搜索。
- **多用户：** 管理员管理公共藏书，普通用户管理本人进度、书签、短评与连读/时长/周期统计；不是每人独立私有书库。首个管理员创建时可承接旧全局进度/活动及无主 KOReader 账户。管理员保护规则见[部署指南](getting-started.zh-CN.md)。
- **在线元数据：** Bangumi（默认）、AniList、MangaDex 无需配置 API key；MyAnimeList 需 Client ID，Comic Vine 需 API Key。在线源会外联，并使用有上限的退避重试和 `Retry-After`。全库/单库的「预取识别证据包」在任务中心运行：为未处理、还没有证据包的系列按来源限速搜索各来源并保存证据包，可暂停、取消，再次发起时从还没备好的系列继续。每次资料库扫描（含 agent 发起的）结束后，会自动对该库串联一次增量预取，只为这次扫描新建的系列准备证据包，不碰原有积压，服务重启后会续跑；领取到的证据包超过 30 天时先在后台刷新、暂不发放；新启用 MyAnimeList 或 Comic Vine 后，查无此作的系列只针对新来源重新变为可处理。单系列手动搜索里挑中目录来源的条目，即记为所有者确认的识别，并按与 agent 识别相同的策略补充（只填空、来源优先级可配置、标签经过滤）；挑中之前排除过的条目会先确认，确认后解除排除。LLM 结果不指向来源条目，仍生成提案，按字段比较、记录置信度，支持去重、单条/批量应用驳回、字段锁和来源溯源。**审核中心 → 待人工**集中列出 agent 上报和新书线索矛盾的系列：挑候选、否决候选、判查无此作、重搜、确认被质疑的识别无误，或设为已审定让识别流程不再碰它。系列详情页列出各来源的识别结论、确认者与时间，可撤换或撤回；资料库筛选可按识别状态过滤。Bangumi 有 `bgm.tv` 外链，其他来源 URL 保留在审核条目。
- **LLM：** 可选 Ollama 或兼容 OpenAI `/v1/responses`、`/v1/chat/completions`，可配置端点/模型/密钥/超时并测试连接（有 SSRF 检查）。可用于元数据、未归入合集系列的主题分组建议（每次最多约 50 系列、建议 3–5 组，需审核）、带理由阅读推荐（按语言缓存 24 小时）。统一收件箱汇总元数据与分组审核，但不把它们当同一种提案。模型输出不是权威事实；远程服务会接收相关提示/藏书元数据，可能收费；基本自托管阅读无需开启它们。
- **超分辨率：** 自行安装 [waifu2x-ncnn-vulkan](https://github.com/nihui/waifu2x-ncnn-vulkan/releases) 或 [Real-CUGAN](https://github.com/nihui/realcugan-ncnn-vulkan/releases)，需要合适的 Vulkan 硬件/驱动，另有各自许可证。设置中填可执行文件绝对路径，再在阅读器滤镜选择引擎、1/2/4/8 倍、降噪及 WebP/PNG/JPG 输出。路径校验只检查存在，非绝对配置在阅读时忽略并回退 PATH / `./bin` 查找；处理按需进行、内存/磁盘缓存、受并发限制，失败回退 Lanczos3，并非预先重写全库。

在线元数据源会对 `429` / `5xx` 有上限地指数退避，并尊重 `Retry-After`；这不保证供应商可用性。LLM 连接设置与具体选项以设置页及[配置模板](../config.example.yaml)为准，不必开启任何在线源即可扫描和阅读。超分辨率工具的参数也以当前阅读器和各引擎帮助为准，配置路径存在并不代表程序能执行或 GPU 兼容。

## 用户与网页阅读

支持翻页、纵向虚拟滚动、双页、画幅适配、书签和图像选项。翻页模式支持 LTR/RTL；瀑布流始终纵向。原始/等宽/等高/适屏、预加载与下一册预取、超窗口图像释放可适配不同设备。翻页支持捏合、双击 2.5 倍、Ctrl+滚轮和拖拽缩放平移，上限 4 倍。

阅读器提供 base/Comimi 主题、护眼暖色叠层、自动裁边、重采样滤镜、带备注书签，以及会话级 WebP/JPEG 传输格式与画质选择。AVIF 用于封面缩略图，不是阅读页直出格式。

整册离线下载使用当前浏览器的 Cache Storage 与 Service Worker，通常需要 **HTTPS 或 localhost**；手机访问局域网 HTTP 地址不等于 localhost。离线进度可在重新联网后按同一账号回传。缓存受浏览器容量、回收和清理站点数据影响，退出登录/切换用户会按归属规则清理，不能当永久备份或跨浏览器通用下载。

## 客户端与进度

三种协议分别启用，均默认关闭；不存在任意客户端都能写回进度的保证。

| 入口 | 能力 | 启用与限制 |
| --- | --- | --- |
| OPDS 1.2 | 导航、原包获取、PSE 分页流式、续读/最近添加、合集、阅读列表、智能合集和 OpenSearch | HTTP Basic（站点用户名/密码），目录 `/opds/v1.2/`；客户端支持程度需实测，不承诺进度写回。 |
| Mihon API | 系列/卷册、标签/作者/状态筛选、合集/列表，以及进度写入端点 | HTTP Basic，入口 `/api/mihon/v1`；需要实现该 API 的适配器，不表示已有公开扩展或上游收录。 |
| KOReader | kosync 设备进度保存，匹配后对账到站点用户 | 独立每账户同步密钥，默认路径 `/koreader`；需绑定站点用户、匹配书籍身份与已知页数。 |

管理员创建的账号必须先在网页完成首次改密。仅下载原包不代表客户端会回传进度。

KOReader 默认二进制哈希匹配，也支持路径指纹模式及可选忽略扩展名。二进制身份是整文件 MD5，不是快速采样哈希；路径模式归一分隔符/大小写并取末三级，不能保证任意路径都匹配。需先按需生成书籍身份；匹配成功且页数已知时，才有条件按绑定用户写入站点进度。管理员可新建、轮换密钥、启停、删除账户，以及重建标识/校准未匹配记录。自助注册仅在站点单用户时尝试自动绑定，多用户不猜归属。

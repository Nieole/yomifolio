## 责任

组合跨功能的完整应用用例，负责同步保存与后台工作的效果交接。后台工作让手动、监听、定时、串联和恢复走同一条发起链；`Runs.Start` 是共享准入入口的应用包装，不是第二个调度器，`DecorateRunContext` 为任务日志附上本次运行与诊断键。同步配置发布、资料库管理和系列编辑不因位于应用层就必须任务化。

扫描编排持有扫描声明、封面批派发及清理收尾；维护编排组合重建、哈希回填和保留清理；智能生成编排持有付费生成的运行策略与生命周期；磁盘作业编排组合外部传输与 ComicInfo 回写；迁移编排交接监听、缓存和外部会话。各能力声明自己的重启方式，由 `mm-runtime` 统一装配。

## 边界与内部边

后台工作通过 `Runs` 发起；同步用例直接返回保存结果，不以运行状态代替提交事实。应用能力通过窄效果端口交接监听、传输发布和缓存失效，不得让功能实现反向依赖应用编排。迁移编排注入可暂停输入和清理派生状态的钩子，不复制持久迁移规则。

`configuration` 返回同一次串行保存的配置、校验与发布结果，区分文件保存、共享快照发布和消费者生效时机；可变配置及跨持久参与者补偿仍归 `config.Manager`。`libraries` 区分资料库已保存、watcher 是否接管、初始扫描是否准入及警告；删除先封闭访问、等待真实占用退出，再独占删除并退休身份，后置效果不能冒充未提交。已有藏书的根路径变更须交给迁移用例。

`seriesediting` 组合来源规则、事务和返回投影：单系列手工保存将元数据、统计和结果读取放在同一事务内，失败不提交；批量增量编辑的元数据整体提交，后置统计失败单独返回，不撤销已提交编辑。来源规则仍归领域能力，SQL 与事务执行仍经持久端口，不在 HTTP 适配器中重建保存配方。

系统级索引重建等待所有已发起的强制资料库扫描；任一单库摄入失败都携带资料库身份与路径向维护运行传播，不能记录 completed。扫描错误可合并；上下文取消仍优先作为取消结果传播，收尾等待已发起扫描结束。

不得把规则、SQL 事务或协议请求解析搬进总编排对象。后台运行的能力、重启安全性与取消语义按具体工作声明，不能因为有通用控制端点就承诺所有工作可暂停、可取消或自动续跑。

维护扫描错误传播由真实 HTTP 回归 `TestSearchMaintenanceMissingLibraryFailsHTTP` 守卫；有效归档成功路径由 `TestSearchFullMaintenanceWithRealArchiveHTTP` 守卫。

已知限制：系统级重建与单库扫描具有不同任务身份，仍可能同时扫描同一库；资料库清理刻意脱离取消，以完成收尾；待执行封面批保存在无固定上界的内存队列中。

## 受限委托访问

`delegated.Service` 拥有独立凭据管理及受限系列读取；`delegated.SQLStore` 是由装配根创建的持久端口实现，不向协议适配器交出 SQL。管理用例在事务内重新检查当前管理员及目标用户，签发绑定真实用户、显式资料库集合与五项独立能力（read、metadata_write、scan_control、internal_llm、cleanup）的凭据。空集合不表示全部；已有凭据只能移除资料库或能力，不能换用户、改名、恢复已撤销项或扩权，扩权须另签发。原始 256-bit 随机 Bearer 密钥只在签发结果出现一次，库内仅保留 SHA-256 摘要；撤销状态持久保留，密码变更的事务失效规则归 `mm-database`。

`delegated.Subject` 只携带 user_id 与 credential_id，供后续运行与操作持久归属；它不是授权快照，不应接受 agent 自报的身份。`Authenticate` 从密钥解析当前主语；`Authorize` 每次查询当前凭据、用户存在性、改密要求与角色，求当前账号许可、凭据资料库及能力的交集。当前账户模型没有额外的用户资料库 ACL，普通用户已有全库目录读权限，但委托只读凭据仍受所选资料库限制；非 read 能力一律还要求当前管理员身份，普通用户不获得管理或付费权限。

### 受限发现与本地线索

`FindSeries`、`ListBooks`、`GetBookClues` 拥有完整只读用例；SQL 持久端口负责查询，`bookcontent` 负责实际本地内容。协议层不直查 DB 或拼接归档访问。查询不扫描、不写入维护状态、不改变网页筛选或扫描摄入。

- 系列条件取交集：`library_ids` 内 OR（省略或空数组取当前凭据的显式资料库集合），`series_ids` 内 OR（最多 50 个明确目标），时间区间与每个 `missing_fields` 均 AND。显式越界资料库或系列即拒绝整个请求，即使其他过滤条件会排除它；未知明确系列同样拒绝。资料库最多 256 个。
- `added_from` 包含、`added_before` 不包含，均为 RFC3339 时间，比较系列持久 `created_at` 的时间点；上下界都提供时须严格递增。它不是完整增量水位，不承诺扫描完成或维护状态。
- 缺失字段只接受 title、summary、publisher、status、language、rating、authors、tags、source_links；描述字段按 SQLite trim 后空或 NULL，评分仅 NULL，集合按没有关联成员判定。零分不是缺失；锁不参与发现。多个缺失条件必须全部满足，不解析来源内容或标签的语义。
- 系列与书均按稳定 ID 升序 keyset 分页：`after_id` 排他，非负；`limit` 省略或 0 为 20，最大 50，负数或超限拒绝。返回 `next_after_id` 仅在还有匹配结果时存在。游标不是授权，后续请求仍重查权限；无跨请求快照，调用方改变条件即开始另一查询。
- 系列返回稳定系列/资料库 ID；书返回稳定书/系列/资料库 ID、名称、标题、卷号、话号、页数及末级目录名/文件名。按书读取须同时核对所属系列和资料库一致，当前账号与凭据对实际对象的 read 授权不能绕过。`GetBookClues` 按稳定书 ID 按需取单书 ComicInfo，不将整本归档或任意路径暴露给调用方。
- ComicInfo 只返回已建模的身份字段（标题、系列、卷号、话号、作者、画师、出版社）；原始 XML 最多 64 KiB，声明大小和实际解压均受限。状态区分 available、missing、corrupt、unreadable、unavailable、too_large，异常不伪造空元数据或把缺失宣称为有效证据；底层路径和错误不返回。
- 单次成功的结构化 JSON 最多 240 KiB，为 256 KiB 工具结果预留协议开销；超限整个请求失败，不静默截断证据。文本块只指向结构化内容，避免 SDK 自动复制一份数据。调用方可减小分页或缩小目标；单对象仍超限须明确失败。

### 受限图片证据

`SeriesCover` 与 `PageThumbnails` 是完整只读应用用例，复用同一 `bookcontent.Service` 与资料库访问资格。封面按目录规则选择系列内首个已有封面的书（sort_number、name，稳定 ID 破同序），读取当前封面缓存，而非假定第一页是封面；不存在缓存明确失败。页面请求必须给出系列与书 ID，两者及实际资料库须一致；直接书 ID 不能绕过系列或库授权。每次按当前用户 ∩ 凭据 ∩ 实际对象重新授权，物化完成后再查当前权限。响应与错误不携带宿主路径。

- `PageThumbnails` 只接受 1–3 个不同的一基页码；空数组、重复、非正数、越界或任何一页失败，整个请求失败，不返回部分证据。没有 after/offset/cursor、整书模式或原始文件回退。重复请求仍只能得到固定低分辨率证据，不提供无损/原图拼接通道；这不是跨请求阅读次数配额。
- 固定 JPEG、最长边 384 像素、保持比例且不放大，每张编码后最多 96 KiB。使用严格解码/重编码路径，不复用普通阅读器的处理失败原图回退；输入解压与像素限制归 `mm-bookcontent`、`mm-images`。
- 应用结果将图片字节计入 base64 后的实际 JSON 大小，并为协议预留 4 KiB；总预算为 256 KiB。超限请求失败，调用方应减少页数，不自动降为原始文件或静默截断。最终 wire framing 与调用方 JSON-RPC ID 另由 `mm-api` 最终检查，不能只以压缩图片字节数宣称满足预算。
- `ImageEvidence` 的结构化内容只含系列/书 ID 以及按请求顺序的页码、实际宽高；图片仅在 MCP image content 出现一次。工程取值偏向识别而非阅读：三页足以比较少量关键视觉线索，384 像素和 JPEG quality 65 控制细节与成本，单图预算不意味着三张图一定能同时装入整体预算。

`GetSeries` 对实际系列所属资料库重新授权；未知与越界标识均拒绝，白名单返回稳定系列/资料库 ID、名称、标题与末级目录名，不含宿主路径或阅读信息。扫描控制通过 `StartScan`、`GetRun`、`ListRuns`、`WaitRun`、`CancelRun` 复用现有扫描与共享运行引擎。直接访问和列表只暴露同一凭据拥有、且当前仍有实际资料库及声明能力的运行；默认拒绝普通网页任务、其他凭据的任务和未知标识。投影不含路径、技术错误或重启参数。列表每页最多 100 条，按稳定 run_id 降序游标查询；等待最多 30 秒，等待期间及返回前重查权限。超时、HTTP/stdio 断连或等待请求取消都不取消业务运行。

`PrepareRun` 为单资料库委托工作持久保存用户、凭据、实际资料库和所需能力（运行 Args），并以凭据隔离任务变体，避免不同权限主体或网页扫描的队列声明互相合并。归属与新运行在同一事务落地，失败不得执行。`ExecutionCheck` 在排队放行及任务体执行前重新鉴权；执行上下文的 `taskcontrol.Wait` 检查点检查当前权限，失效后协作取消整个上下文。已提交内容不回滚，已发网络请求与费用不保证追回。扫描仅作非强制摄入准备，不串联独立封面或哈希回填任务，避免绕过委托归属及持续授权；普通扫描的串联行为不变。

run_id 标识一次已接纳执行，不是系列变更的 operation_id，也不是请求幂等键。扫描请求重试不保证 exactly-once：仅在同凭据、同任务已有排队项时沿用既有队列合并并返回 coalesced，保留原声明；否则接纳另一条运行。客户端不确定受理结果时应先列表查询，不可把合并当作幂等保证。未来系列操作及额度需独立持久标识，不得复用扫描合并计数。委托任务变体不登记重启/重试入口：重启只将遗留运行记为 interrupted，绝不自动继续扫描或重新发出付费调用；重新发起须当前授权。

供后续来源、写入、模型及撤销用例复用的边界是 `PrepareRun`（准入/归属）、`Checkpoint`（外部请求前及可中断单元间）和 `AuthorizeTx`（在实际写入的同一 SQLite 事务内读取当前权限）。权限查询不是权限快照；事务冲突必须整笔中止，重试须开新事务并重新鉴权。禁止把事务外 Authorize 当作写入 fencing，也不得把数据库授权检查宣传为可追回网络请求。当前不提供系列元数据落库、提案裁决或清理工具。

### 多来源匹配与确认提案

`SearchSources`、`GetSourceSearch`、`ProposeMatch`、`GetMatchProposal` 归 `delegated.Service`，协议不接触数据库，也不借网页刮削路由绕过委托。搜索和读取映射 read；**构建持久提案也是写入**，须 metadata_write 及当前管理员权限，普通账号即使凭据含写能力也不能创建。直接读取提案还须核对请求系列及提案所属系列，不接受书 ID、来源 ID 或源 URL 代替目标授权。

搜索通过同一 `Runs.Start`、`PrepareRun` 和当前权限检查点异步执行。可用来源是 Bangumi、AniList、MangaDex，以及当前配置具有对应凭据的 MyAnimeList、ComicVine；不调用任何 LLM 别名，不产生模型费用。工厂沿用装配根外部来源接缝，配置在执行时读取。每个来源前后检查权限和取消；单源失败不隐藏其他可用结果，全失败运行失败，部分可用明确 partial。取消后不能从该搜索创建提案；客户端断线不取消运行。列表允许 read 或 scan_control 进入，但每条运行仍须其自身原声明能力。

搜索输入只接受已授权系列、最多 256 字节查询、每源 1–10 个候选（默认 5），offset 为 0–1000 且为 limit 整数倍。每源返回来源 total、可提交的 next_offset 与独立状态；next_offset 仅在来源仍有结果、当前页非空且 offset+limit 不超过 1000 时返回，始终沿用同一 limit 的整数倍，不钳制成不对齐的 1000。非空来源页仍有后续但下一页超出 offset 上限时，省略 next_offset 并返回 truncated=true；这是有界搜索停止，不表示来源已无后续，也不额外抓取或扩大单页预算。来源 total 尾页不标记 truncated。每个候选最多 32 KiB，标签/作者各最多 100 项，来源 ID/册数非负，来源适配器的十分制评分须在 0–10 内（0 表示未提供），非有限数值拒绝；来源不得携带匹配决策记录，整体沿用 240 KiB 结果上限。非法或超大源结果整源标记不可用，不静默截断字段。候选详情使用现有搜索适配器返回的完整已建模身份/版本、日期、册数、描述、作者等数据快照；不调用按标题取首项的 FetchSeriesMetadata 伪装成指定候选详情。所有来源 URL/封面链接仅为数据，任何候选 ID、URL 都不成为任意网络获取参数。

临时搜索快照按凭据和实际系列绑定，最多同时保留 64 次，30 分钟后或进程重启失效；运行归属与历史仍按运行契约持久保留，不能把历史运行号当作已持久化候选。快照不会建立未定提案积压。每次读取重查当前实际资料库；创建时还在实际 SQLite 提案事务内 `AuthorizeTx` 并重读系列所属库、当前字段值与锁。事务冲突整笔失败，不带旧授权重试。

agent 必须显式确认所选候选属于同一系列及相同版本，并提交最多 1000 字节的可核查短摘要；无法确认时仅返回候选和疑点，不持久化探索结论或内部推理。字段选择把 title、summary、publisher、status、rating、tags、authors 各映射到本次搜索返回的 candidate_id，允许跨来源组合；不开放 cover/source_links 等未支持提案字段。confidence 保持来源质量信号，不包装为身份匹配概率，不自动确认首项。

确认结果交给 `proposal.Queue`，保留 queued、reused_existing、no_changes、all_fields_locked、rejected_before 的区别，`metadata_written` 恒 false；复用时返回原提案及其原证据，不谎称本次摘要已存入。新建提案 raw_payload 保存 `MatchEvidence`（真实用户/凭据归属、查询、身份及版本确认、短摘要、每字段选定来源的完整已建模数据快照），字段行同时保存各自 source/source_url。证据随提案持久化，重开服务仍可按系列和提案读取；这不是元数据变更审计或可撤销操作历史，后续写入需另建前后状态及审计记录。链接和封面出现在证据内不代表可裁决。读取当前字段值/锁复用 `proposal.Get`，不展示入队快照为当前事实。

### 内部模型次数额度

`AssessMatch` 将一个已完成/部分完成的来源搜索的**全部候选快照**绑定为一个不可变模型操作，不接受客户端自选候选子集、任意提示词或来源 URL。`search_id` 由服务端产生；同凭据同搜索永久对应同一个 `model-budget:` 命名空间的 operation_id，type 为 match_assessment。操作持久绑定真实 user_id、credential_id、实际资料库/系列及最初明确转述的 allowance（1–50 次）；重复声明仅返回原操作，额度不同即拒绝，不新建运行、不重置计数。新的服务端搜索是新的操作，须再次明确声明本次额度；按 `mm-adr-0016` 的委托边界，这不是独立证明用户同意，也不对恶意 agent 伪造新的用户指令作保证。凭据独立 internal_llm 能力、当前管理员权限和实际资料库范围不可被声明扩大；read 同时用于实际系列/证据访问。普通用户即使凭据带模型能力仍被拒绝。未声明额度及普通查询绝不调用模型；07 来源搜索默认行为不变。

操作独占一次共享引擎运行；不注册付费重试/恢复配方。运行 Args 原子保留委托归属和 model_operation_id，操作先持久化，再准入运行；运行体在 run_id 经当前权限事务关联成功前不得发请求。HTTP/stdio 断开不取消已准入运行；关联阶段不继承请求取消。若准入/关联故障或崩溃，操作可停留 not_started/未知结果，不自动修复为重发；重复请求只读取原操作。外部效果和运行准入不与额度声明构成分布式原子事务，不能宣称 exactly-once 成功。

`CallBudgetedModel` 是供后续可信应用调用者复用的深边界：对冻结候选的 item 索引，在同一 SQLite 事务内 `AuthorizeTx` 检查当前模型/read 权限和系列实际归属，以 used<allowance 及唯一 (operation_id,item) 原子预留并增加 used。并发、跨请求、断线重连和进程重启都不能重复消费同一 item 或增加 allowance；数据库 busy/snapshot 冲突整笔中止，无带旧授权的自动重试。used 表示**准入即消耗**，并非确认上游已收费的次数：失败、超时、解析错误、取消、预留后未发送及进程崩溃均不退款。上游是否收到请求无法确认时 outcome 保留 unknown；未预留项为 unprocessed。remaining=allowance-used 仅是未消耗的额度，不允许为同一操作自动续跑或重试。重启只沿用持久记录和运行 interrupted 语义，绝不恢复发送付费请求。计数不承诺货币费用上限。

每个可中断单元及调用前执行 `taskcontrol.Wait` / `Checkpoint`、重读当前授权；生产模型来源还在实际 HTTP 请求前再次执行当前权限守卫，禁用该次调用的重定向、请求体重放配方及重复 HTTP 请求（含 HTTP/2 透明重试）；不改变普通模型用例的默认传输行为。取消按共享引擎/06 的协作语义；撤权停止后续请求和结果写入，但数据库事务与网络发送不是一把可回溯锁，检查后撤销与已发请求/费用不能追回。所有新操作、run_id 关联、额度及结果写入均在实际事务内重新鉴权；撤权导致结果无法落库时保留已消耗的 unknown，不为了收尾绕权写入。

`GetModelOperation` 只向同用户且同凭据、当前仍获模型/read 权限的调用方提供持久投影；未知及跨凭据/用户 ID 拒绝。额度与逐项状态来自同一数据库读快照，返回 used、remaining、所有候选 outcome 和 unprocessed 列表及 run_id；运行取消/中断状态沿现有运行查询。模型失败不隐藏尚可执行的非模型检索、读取或显式确认提案工作。

模型仅提供 consistent/different/uncertain 三类辅助标签；非法返回报告 invalid_response，调用失败报告 failed，不存原始输出、内部推理、技术错误或模型分数。不保存模型结论为系列事实、不自动确认身份/版本、不创建或裁决提案、不参与站点综合评分。仍须通过07的独立显式确认与字段来源证据才能创建提案。额度表不是元数据变更审计；08可未来通过独立命名空间 ID 关联，12不实现元数据写入、撤销、封面或清理。

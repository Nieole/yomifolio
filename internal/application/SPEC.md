## 责任

组合跨功能的完整应用用例，负责同步保存与后台工作的效果交接。后台工作让手动、监听、定时、串联和恢复走同一条发起链；`Runs.Start` 是共享准入入口的应用包装，不是第二个调度器，`DecorateRunContext` 为任务日志附上本次运行与诊断键。同步配置发布、资料库管理和系列编辑不因位于应用层就必须任务化。

扫描编排持有扫描声明、封面批派发及清理收尾；维护编排组合重建、哈希回填和保留清理；智能生成编排持有付费生成的运行策略与生命周期；磁盘作业编排组合外部传输与 ComicInfo 回写；迁移编排交接监听、缓存和外部会话。各能力声明自己的重启方式，由 `mm-runtime` 统一装配。

## 边界与内部边

后台工作通过 `Runs` 发起；同步用例直接返回保存结果，不以运行状态代替提交事实。应用能力通过窄效果端口交接监听、传输发布和缓存失效，不得让功能实现反向依赖应用编排。迁移编排注入可暂停输入和清理派生状态的钩子，不复制持久迁移规则。

`configuration` 返回同一次串行保存的配置、校验与发布结果，区分文件保存、共享快照发布和消费者生效时机；可变配置及跨持久参与者补偿仍归 `config.Manager`。`libraries` 区分资料库已保存、watcher 是否接管、初始扫描是否准入及警告；删除先封闭访问、等待真实占用退出，再独占删除并退休身份，后置效果不能冒充未提交。已有藏书的根路径变更须交给迁移用例。

`seriesediting` 组合来源规则、事务和返回投影：单系列手工保存将元数据、统计和结果读取放在同一事务内，失败不提交；批量增量编辑的元数据整体提交，后置统计失败单独返回，不撤销已提交编辑。来源规则仍归领域能力，SQL 与事务执行仍经持久端口，不在 HTTP 适配器中重建保存配方。

系统级索引重建等待所有已发起的强制资料库扫描；任一单库摄入失败都携带资料库身份与路径向维护运行传播，不能记录 completed。扫描错误可合并；上下文取消仍优先作为取消结果传播，收尾等待已发起扫描结束。

不得把规则、SQL 事务或协议请求解析搬进总编排对象。后台运行的能力、重启安全性与取消语义按具体工作声明，不能因为有通用控制端点就承诺所有工作可暂停、可取消或自动续跑。

维护扫描错误传播由真实 HTTP 回归 `TestSearchMaintenanceMissingLibraryFailsHTTP` 守卫；有效归档成功路径由 `TestSearchFullMaintenanceWithRealArchiveHTTP` 守卫。

已知限制：系统级重建与单库扫描具有不同任务身份，仍可能同时扫描同一库；资料库清理刻意脱离取消，以完成收尾；待执行封面批保存在无固定上界的内存队列中。

## 受限委托访问

`delegated.Service` 拥有独立凭据管理及受限系列读取；`delegated.SQLStore` 是由装配根创建的持久端口实现，不向协议适配器交出 SQL。管理用例在事务内重新检查当前管理员及目标用户，签发绑定真实用户、显式资料库集合与五项独立能力（read、metadata_write、scan_control、internal_llm、cleanup）的凭据。空集合不表示全部；已有凭据只能移除资料库或能力，不能换用户、改名、恢复已撤销项或扩权，扩权须另签发。原始 256-bit 随机 Bearer 密钥只在签发结果出现一次，库内仅保留 SHA-256 摘要；撤销状态持久保留，密码变更的事务失效规则归 `mm-database`。

`delegated.Subject` 只携带 user_id 与 credential_id，供后续运行与操作持久归属；它不是授权快照，不应接受 agent 自报的身份。`Authenticate` 从密钥解析当前主语；`Authorize` 每次查询当前凭据、用户存在性、改密要求与角色，求当前账号许可、凭据资料库及能力的交集。当前账户模型没有额外的用户资料库 ACL，普通用户已有全库目录读权限，但委托只读凭据仍受所选资料库限制；非 read 能力一律还要求当前管理员身份，普通用户不获得管理或付费权限。

### 受限发现与本地线索

`FindSeries`、`ListBooks`、`GetBookClues` 拥有完整只读用例；SQL 持久端口负责查询，`bookcontent` 负责实际本地内容。协议层不直查 DB 或拼接归档访问。查询不扫描、不写入维护状态、不改变网页筛选或扫描摄入。

- 系列条件取交集：`library_ids` 内 OR（省略或空数组取当前凭据的显式资料库集合），`series_ids` 内 OR（最多 50 个明确目标），时间区间与每个 `missing_fields` 均 AND。显式越界资料库或系列即拒绝整个请求，即使其他过滤条件会排除它；未知明确系列同样拒绝。资料库最多 256 个。
- `added_from` 包含、`added_before` 不包含，均为 RFC3339 时间，比较系列持久 `created_at` 的时间点；上下界都提供时须严格递增。它不是完整增量水位，不承诺扫描完成或维护状态。
- 缺失字段只接受 title、summary、publisher、status、language、rating、authors、tags、source_links；描述字段按 SQLite trim 后空或 NULL，评分仅 NULL，集合按没有关联成员判定。零分不是缺失；锁不参与发现。多个缺失条件必须全部满足，不解析来源内容或标签的语义。
- 系列与书均按稳定 ID 升序 keyset 分页：`after_id` 排他，非负；`limit` 省略或 0 为 20，最大 50，负数或超限拒绝。返回 `next_after_id` 仅在还有匹配结果时存在。游标不是授权，后续请求仍重查权限；无跨请求快照，调用方改变条件即开始另一查询。
- 系列返回稳定系列/资料库 ID；书返回稳定书/系列/资料库 ID、名称、标题、卷号、话号、页数及末级目录名/文件名。按书读取须同时核对所属系列和资料库一致，当前账号与凭据对实际对象的 read 授权不能绕过。`GetBookClues` 按稳定书 ID 按需取单书 ComicInfo，不将整本归档或任意路径暴露给调用方。
- ComicInfo 只返回已建模的身份字段（标题、系列、卷号、话号、作者、画师、出版社）；原始 XML 最多 64 KiB，声明大小和实际解压均受限。状态区分 available、missing、corrupt、unreadable、unavailable、too_large，异常不伪造空元数据或把缺失宣称为有效证据；底层路径和错误不返回。
- 单次成功的结构化 JSON 最多 240 KiB，为 256 KiB 工具结果预留协议开销；超限整个请求失败，不静默截断证据。文本块只指向结构化内容，避免 SDK 自动复制一份数据。调用方可减小分页或缩小目标；单对象仍超限须明确失败。

`GetSeries` 对实际系列所属资料库重新授权；未知与越界标识均拒绝，白名单返回稳定系列/资料库 ID、名称、标题与末级目录名，不含宿主路径或阅读信息。扫描控制通过 `StartScan`、`GetRun`、`ListRuns`、`WaitRun`、`CancelRun` 复用现有扫描与共享运行引擎。直接访问和列表只暴露同一凭据拥有、且当前仍有实际资料库及声明能力的运行；默认拒绝普通网页任务、其他凭据的任务和未知标识。投影不含路径、技术错误或重启参数。列表每页最多 100 条，按稳定 run_id 降序游标查询；等待最多 30 秒，等待期间及返回前重查权限。超时、HTTP/stdio 断连或等待请求取消都不取消业务运行。

`PrepareRun` 为单资料库委托工作持久保存用户、凭据、实际资料库和所需能力（运行 Args），并以凭据隔离任务变体，避免不同权限主体或网页扫描的队列声明互相合并。归属与新运行在同一事务落地，失败不得执行。`ExecutionCheck` 在排队放行及任务体执行前重新鉴权；执行上下文的 `taskcontrol.Wait` 检查点检查当前权限，失效后协作取消整个上下文。已提交内容不回滚，已发网络请求与费用不保证追回。扫描仅作非强制摄入准备，不串联独立封面或哈希回填任务，避免绕过委托归属及持续授权；普通扫描的串联行为不变。

run_id 标识一次已接纳执行，不是系列变更的 operation_id，也不是请求幂等键。扫描请求重试不保证 exactly-once：仅在同凭据、同任务已有排队项时沿用既有队列合并并返回 coalesced，保留原声明；否则接纳另一条运行。客户端不确定受理结果时应先列表查询，不可把合并当作幂等保证。未来系列操作及额度需独立持久标识，不得复用扫描合并计数。委托任务变体不登记重启/重试入口：重启只将遗留运行记为 interrupted，绝不自动继续扫描或重新发出付费调用；重新发起须当前授权。

供后续来源、写入、模型及撤销用例复用的边界是 `PrepareRun`（准入/归属）、`Checkpoint`（外部请求前及可中断单元间）和 `AuthorizeTx`（在实际写入的同一 SQLite 事务内读取当前权限）。权限查询不是权限快照；事务冲突必须整笔中止，重试须开新事务并重新鉴权。禁止把事务外 Authorize 当作写入 fencing，也不得把数据库授权检查宣传为可追回网络请求。当前没有元数据写入、LLM 或清理工具。

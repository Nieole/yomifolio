## 责任与边界

集中书来源、页清单、页图变体、派生缓存资格与原文件读取，避免协议适配器各自组合归档借还及缓存规则。内容不包含读者身份或阅读位置；协议错误映射和后台运行准入归调用方。

## 访问与缓存契约

页码为一基，越界明确失败。页读取在返回独立字节前归还归档借用；共享缓存返回的字节按不可变数据消费。整书读取返回原文件句柄，不做解码，直到幂等 `Close` 才释放归档及资料库访问资格，读到 EOF 不等于关闭。整书打开须在资料库准入后复核访问版本，避免迁移期间使用旧来源。

来源版本和请求的加工选项共同决定页变体，不能把不同文件或不同加工结果混作缓存命中。仅实际生成的派生图进入加工缓存；原图直通、不可用滤镜及加工失败回落不冒充成功加工。缓存是可丢弃的派生状态，不替代归档原文件。

`Service.ComicInfo` 按书 ID 与调用方已授权的资料库 ID 解析当前来源，来源改属其他库时拒绝；在资料库准入后复核访问版本，读取期间持有卷 IO 许可与共享归档借用，返回前全部归还。只提供有界本地身份线索，缺失、损坏、无法读取和超限分别报告；不返回宿主路径、原始 XML 或文件句柄。委托用户与凭据权限仍由应用层负责。

## 受限图片物化

`Service.Evidence` 按稳定书 ID 与调用方已授权资料库 ID 重查来源，在资料库准入后复核访问版本；路径迁移期间不得复用旧路径快照。页面由现有共享归档池借用，封面只从当前来源的持久缓存键读取，普通键限定于缩略图缓存根；已提交封面的 metadata-covers 虚拟键按 mm-application 的不可变材料布局限定到相邻私有根。两种根均使用 os.Root，不允许键或符号链接逃出对应根。调用方不能指定宿主路径。读取与加工期间保留现有库读资格和卷 IO 许可；归档、封面文件与资格均在成功、错误、取消时释放，不交出流或句柄。

证据页目录使用 `parser.GetPagesLimited`，选页使用 `parser.ReadPageLimited`；两者的 RAR reader 从创建起都受固定 16 MiB 字典上限约束，目录枚举、卷读取及 solid 前置条目解压均观察取消。等待普通 RAR 会话锁同样可取消，返回前释放证据槽、库读资格、卷 IO 许可和归档借用，不必等待普通阅读 IO 解锁；已获取锁的独立 reader 仍与归档关闭互斥。目录或选页的字典/跳过条目/目标条目超限统一映射 `ErrEvidenceLimit`，不回退原始下载或普通无界读取；RAR 未选中的超限条目也可拒绝本次证据请求。每个源条目最多 16 MiB，声明大小和实际解压都检查；这与普通归档读取的 256 MiB 大条目安全上限独立，更不等于工具响应预算。实际解码与严格缩略图结果归 `mm-images`。独立的可取消双槽限制在读取输入前申领，封顶证据请求同时保留的输入/解码内存，不随 CPU 核数扩大。等待取消立即释放已有准入；已进入同步解码/缩放的调用在有界 CPU 单元完成后观察取消，不承诺中断 Go 解码器内部指令。普通页缓存/原书访问语义不变。

## 发布交接

ComicInfo 发布遵循 `mm-adr-0015`；底层归档暂存与发布排空归 `mm-parser`。文件提交后，`Publisher.Publish` 交接文件事实更新与缓存失效，分别返回 `Committed` 和后续 `Warning`。提交后的请求取消不能撤销文件替换，也不能跳过有界后置交接；调用方须展示告警，不能将它解释成文件未写入并自动重写。

核对入口：`Service.Open`、`Service.Page`、`Publisher.Publish`；`file_test.go`、`page_test.go`、`publication_test.go` 与 `memory_cache_test.go`。

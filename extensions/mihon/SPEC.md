## 责任

向官方 Mihon 提供 Manga Manager 藏书源：目录、最近添加、搜索和筛选、系列详情、卷册、页图及客户端下载。读取资料库、合集、智能合集和阅读列表；组织目录保持服务端顺序，不将书架导航伪装成可任意组合的搜索。

## 身份与连接

五个槽位使用固定 source ID，独立保存服务根地址和站点 Basic 凭据。条目 URL 绑定规范化根地址和原样账户名，密码不进入身份；更换服务器或账户后拒绝旧条目网络请求，改密不改变条目身份。离线文件与 Mihon 已有缓存不因设置变更自动删除，不承诺远程撤销已下载内容。

密码键使用官方稳定版支持的 `__PRIVATE_` 前缀，默认源备份排除，仅显式包含敏感偏好时导出；普通备份恢复后重新输入密码。源构造完成前同步提交旧密码键迁移并移除旧键，已有私有键（包括空值）优先，提交失败拒绝源初始化。无旧键不写入；迁移不改变槽位 ID、账户绑定或网络认证，不需要改动客户端。

认证只发送到配置的 origin 与协议路径范围；拒绝重定向、路径逃逸及含凭据的 URL。协议根相对资源路径在客户端重映射至配置的反代前缀，服务端不信任客户端转发头推导公开前缀。每槽位使用独立 HTTP 客户端，不继承共享 cookie、认证或日志拦截器，代价是不继承 Mihon 自定义网络扩展。

## 映射契约

服务端一基页码在边界转为 Mihon 零基页索引；章节列表按官方源接口顺序返回，不以章节号重新推断组织顺序。作者、画师和标签读取系列详情，不从全站字典猜测。选定组织目录后不支持的组合条件明确报错，不静默忽略。

## 构建与发布

独立 CI 在无签名秘密的条件下分别报告协议与发布工具测试、调试构建及 lint；日常筛选及汇总门禁原则归 `mm-architecture`。手动签名发布仅允许默认分支，签名前必须完成同一提交的当次全量无秘密验证：构建 job 仅读权限，发布 job 写权限，令牌仅传最终发布入口；keystore 只暂存 runner 临时目录，不进入仓库或公共产物。

发布工具从已验证 APK 读取包名、版本、内容哈希与证书，不复制源代码中的身份列表。标准旧格式索引由 `repo.json` 与 `index.min.json` 提供，nullable sources 留空，由 APK 工厂决定实际源。索引、APK、现有项目图标及可验证签名历史在独立分支一次非强推更新；保留无关文件与历史 APK，竞争更新失败。

禁止调试／未签名 APK、降级、同 code 不同字节、证书变更及缺失可验证历史的自动覆盖；同字节重试幂等。发布配置不改服务端 release 通道。四个签名秘密及真实发布需维护者配置，私钥不由工具生成或代管。APK 使用官方加载器兼容的 `1.4.<revision>` 格式，与编译依赖版本分离。

## 同步与验收边界

交付仅包含独立源 APK 和自有扩展更新仓库，不修改或分发 Mihon 客户端及其阅读器库改动，不提供跨端页级双向同步。源 APK 不接收真实阅读事件，不因图片请求、预加载或下载写进度；服务端进度接口不能扩大普通源插件的能力。

以官方 v0.21.3 的源加载契约验证；构建和协议单测不替代真机加载、下载离线阅读、多账户及真实反代验证。APK 的签名和更新身份必须持续稳定，测试签名不作为公开发布身份。构建及使用操作归同目录 `README.md`。
